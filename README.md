🌗 Interfaith Themes – Mishrin 1.00 Yin–Yang Edition

A minimalist Next.js + Tailwind CSS web app that lets users explore parallel themes (Justice, Truth, Compassion, etc.) across the Bible, Qur’an, and Bhagavad Gita.

This project follows the Mishrin 1.00 framework: unbiased, balanced, and focused purely on wisdom — presented through a Yin–Yang inspired UI for clarity and harmony.

✨ Features

📖 Browse 15 universal themes side-by-side across scriptures

🎨 Yin–Yang inspired design: minimalistic, black & white, balanced

⚡ Powered by Next.js (React framework) and Tailwind CSS

🌍 Deployable to Vercel or GitHub Pages

🧭 Simple navigation between homepage and theme pages
